# ULTRA Crew Video

Desktop video automation toolkit for Windows.

## Main Features

- Crew Video
- Smart Cut
- Stock / Remake
- Relax Loop
- Live Stream
- Subtitle
- Translation
- Dubbing
- Watermark
- FFmpeg video processing
- Multi-platform media download

## Technology

- Python
- PySide6
- FFmpeg
- yt-dlp
- Whisper
- PyInstaller

## Platform

Windows 10 / 11 64-bit
